三档数据的边界：**原件**（`01_原始`、`02_解包`、`04_资源分析\剧情CSV`）永不改写；**修正**另存新目录（`剧情CSV_修正` + `修正版\`）并留 `修正记录.md`；**派生物**随时可从任一管线重算。

两套产物的关系：`修正版\` 是正式交付；顶层 `剧本/剧本AST/表/统计` 是同一套脚本吃原始 CSV 的结果，用于证明「修正前后内容一致，只有 2 行源数据不同」。详见 `04_资源分析\修正版\README.md`。

## 一页速览

- **8 个 CSV 剧本，14,401 行，153,233 汉字**，全部明文；每行三列 `说话人,文本,指令`。
- 全库仅 **18 种指令模式**：`左/中/右` 气泡方向、`分支N` 段结束兼标签、裸数字跳转、`选项,N` 玩家选项、`等待,N`（**分钟**）、`词典`、`图鉴`、`动态`、`语音`、`BE`、`无`(Day 标记)。
- 执行模型是**跳转表**而非线性播放：2,556 处跳转、1,845 段、**零悬空跳转**、187 个纯汇合点、14 个重复标签（歧义待运行时验证）。
- **1,278 个选择点全部严格二选一**；**39 个 BE**；**20 个 Day**；等待合计 **15,471 分钟（≈258 小时）**。
- 词典 111 条（88 条带编号、23 条只写词条名）、图鉴 43 点（43 个唯一键 / 58 张插画）、动态 34 条、语音 2 条。
- 图鉴有**两种形态**：29 行静默解锁，14 行由角色「发图」（`Miko` 13 次、`Iris` 1 次）；`-n` 变体缺文件时**回退基名**。
- 词典释义硬编码在 `libapp.so`（UTF-16LE），98 个释义块中 **20 条**已自证配对；完整 `id→释义` 需 Dart 快照反序列化。
- 签名：v1+v2，**自签名 RSA 证书**，DN 中文字段已被编码破坏成 U+FFFD；无 v3 签名。
- 网络面：仅 11 个 URL 常量、**无埋点/广告/统计**；两处 **明文 HTTP**（`q1.qlogo.cn` 头像、`qm.qq.com` 群链接）。
- 权限面：`REQUEST_INSTALL_PACKAGES` 属高风险声明（静态未见使用）。
- 已修数据缺陷 **2 处**（图鉴键写错列、行尾多逗号）；语义层异常（词典编号 26 空洞 / 2 组重复 / 23 条空编号）**只登记不改值**，因为编号是 `libapp.so` 释义数组的下标。
- 产物分**两套管线**：`修正版\`（读修正后 CSV，正式交付）与顶层 `剧本/剧本AST/表/统计`（读原始 CSV，对比用）；两者正文逐行相同，差异只在页眉标注。
