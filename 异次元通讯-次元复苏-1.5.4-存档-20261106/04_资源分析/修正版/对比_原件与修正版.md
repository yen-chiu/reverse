# 原件管线 vs 修正版管线

两条管线读同一份 APK、同一套脚本，只换输入目录：

```
python -X utf8 00_工具\story_export.py                        # → 04_资源分析\修正版\（读 剧情CSV_修正）
python -X utf8 00_工具\story_export.py 剧情CSV 04_资源分析      # → 04_资源分析\（读 剧情CSV）
```

## 三、结论

- 两条管线的派生产物**没有内容差异**；不同的 9 个文件全部只是标注行不同（剧本页眉的「（修正版…）」提示、对账报告的「数据源」路径），正文逐行相同。
- 原因：`story_export.py` 的取键规则已改为「前两列中最后一个非空字段」，因此即使喂原始 CSV（图鉴键写在第一列、行尾多逗号），解析结果也不再丢失 `S6-01-n`。
- 也就是说：**修正解决的是数据文件本身的规范性**（第三方/朴素解析器按第 2 列取键会静默丢键），而不是改变现有脚本的输出内容。
- 需要「与游戏内实际表现一致」的下游用户，两条管线可任选；需要喂给别的工具、或做二次开发，请用 `剧情CSV_修正\`。
