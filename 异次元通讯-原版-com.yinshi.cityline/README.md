## 复现

```powershell
python 00_工具\story_orig.py            # 剧情结构 + 节奏拟合 + 与重置版保真度对比
python 00_工具\xls_dump.py <x.xls> 03_分析\xls   # 解析 OLE2/BIFF8 表格（多工作表）
```

`AndroidManifest.xml` 是二进制的，先用 `zipfile` 把 `AndroidManifest.xml` 取出来再交给
`异次元通讯-次元复苏-1.5.4-改动/00_工具/axml2xml.py`（直接传 APK 会报 `type=0x4b50`）。

## 关键结论

1. **原版剧情结构**：`chapterId` 是分支节点号，选项自带目标节点（`option1GotoChapterId`），
   配图用文本前缀 `imageN&` 表示；与重置版的 `选项N / 分支N` 标签模型同构。
2. **原版节奏**：`busyWaitTime` 逐条给出「对方输入中」的毫秒数，中位 2.4 秒，
   长句 5–7 秒，离线等待最长 4 小时 —— 重置版把这层信息丢掉了，只留下分钟级 `等待`。
3. **文本保真度 71.5%**：开头几屏几乎一字不差，越往后改写越多（省略号、称呼、句子措辞），
   与访谈中「剧本靠群友回忆收集」相符。
4. **UI 素材同源**：原版 `unknow_miko_avatar.png` 就是灰底问号，重置版 `未知用户.webp` 与其一致，
   网页版的「未认识 = 问号」设定并非自创。
5. 网页移植版已把原版 `busyWaitTime` 用作消息节奏（逐字命中的 591 句取原值，其余走拟合模型）。
