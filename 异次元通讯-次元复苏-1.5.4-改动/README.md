## 目录结构与数据边界

```
异次元通讯-次元复苏-1.5.4-改动\
├─ 00_工具\        27 个 .py（纯标准库；BASE 由脚本位置推导，整个目录可搬移/改名）
├─ 01_原始\        APK 副本（只读）
├─ 02_解包\        ZIP 原样解包（315 条目，保留百分号编码的原始文件名）
├─ 03_反编译\      清单、DEX 各表、libapp.so 字符串语料
├─ 04_资源分析\    剧情CSV\（已修正，唯一数据源）、剧本\、剧本AST\、表\、统计\、数据体检与修正记录.md
├─ 05_报告\        逆向分析报告.md
├─ 06_网页版\miko-web\  网页移植版（静态站：index.html + app.js + style.css + data\ + assets\）
├─ 99_临时\        中间输出（可删）
├─ README.md
└─ 项目清单.md     指纹与一致性证据
```

数据分三档，**只允许单向流动**：

| 档 | 内容 | 规则 |
|---|---|---|
| 证据 | `01_原始\`、`02_解包\`、`03_反编译\` | 永不改写；`02_解包` 与 APK 条目一一对应 |
| 修正 | `04_资源分析\剧情CSV\` | 相对发布包只差 2 行，逐行留痕在 `数据体检与修正记录.md` |
| 产物 | `剧本\`、`剧本AST\`、`表\`、`统计\` | 一律由脚本从 CSV 重算，不手改 |

- **包装**：`com.autumnmoon.miko`，1.5.4 / versionCode 1，minSdk 21 / targetSdk 34；315 个 ZIP 条目，36.7 MB。
- **架构**：Flutter 3 个 ABI（arm64-v8a / armeabi-v7a / x86_64）；`classes.dex` 3,666 类全是 androidx + Flutter 插件 + R8 混淆壳，**无广告/统计 SDK**；游戏逻辑全在 `libapp.so`。
- **签名**：自签名 RSA，v1+v2（无 v3）；证书 DN 的中文已被编码毁成 U+FFFD，不可还原。
- **剧情**：8 个 CSV、14,401 行、616,325 字节 / 153,233 汉字；8,453 条消息、1,278 个选择点（**全部二选一**）、2,556 个选项、1,845 个分支段、1,820 个唯一标签、187 个纯汇合点、**0 悬空跳转**、14 个重复标签；等待合计 15,471 分钟（1–840，单位=分钟）。
- **指令**：全库仅 **18 种模式** —— `左/中/右`（气泡方向）、`分支N`（段结束兼标签）、裸 `N`（跳转）、`选项,N`、`等待,N`（分钟）、`词典`、`图鉴`、`动态`、`语音`、`BE`、`无`。
- **内容量**：词典 111 条（84 正常 + 4 重复 + 23 空编号）、图鉴 43 点/43 唯一键、动态 34、语音 2、BE 39、Day 20。
- **资源**：107 个资产 / 12.9 MB（插画 58、头像图标 13、章节封面 8、音频 8、背景 9、词典图 3、剧本 8）。
